# POLARIS

**Polymer-Oriented Learning and Adaptive Reverse Inference System**

A gated-generative intelligent platform for polymeric mRNA carrier discovery.

---

## Overview

**POLARIS** is a polymer-centric generative learning framework designed to accelerate the discovery of high-performance polymeric mRNA delivery carriers. The platform performs *adaptive reverse inference* from target delivery performance to polymer structure, enabling exploration beyond empirically accessible chemical space.

Starting from a dataset of 1,126 experimentally characterized poly(L-lysine)-based polymers, POLARIS integrates:

* Template-free generative modeling
* Learned gating-based candidate prioritization
* Iterative experimental validation

By synthesizing only 25 generated polymers, POLARIS identified 10 high-performing mRNA carriers (40% hit rate), representing a 12-fold enrichment over conventional empirical screening (3%).

Beyond accelerating discovery, POLARIS provides mechanistic insight into polymer performance, revealing a constrained design manifold governed by coupled polarity, ionizability, and hydrophobic side-chain density.

## Scientific Contribution

This work establishes **gated-generative learning as a materials-native discovery strategy** for polymeric mRNA carriers. Rather than relying solely on forward predictive modeling, POLARIS demonstrates that adaptive reverse inference can:

* Navigate vast polymer chemical space
* Escape empirically explored regions
* Reveal constrained performance-governing manifolds
* Enable efficient closed-loop experimental discovery
